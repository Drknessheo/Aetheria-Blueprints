## How to send USDT / crypto safely
Follow these steps to reduce risk when sending crypto donations:

1. Verify the UID and recipient out-of-band
   - Confirm the UID (786934088) on the project README or by contacting the project owner directly (for example, via the repository owner’s verified contact channels) before sending anything.

2. Choose the correct network and token
   - For USDT, common networks are ERC20 (Ethereum), TRC20 (TRON), and BEP20 (BSC). Confirm which network the recipient accepts. Sending on the wrong network can lead to irreversible loss.

3. Send a small test transfer first
   - Before sending a full donation, send a small amount (e.g., $5 worth) to confirm the UID and network are correct and the funds are received.

4. Include memo / tag if required
   - Some exchange accounts require a memo, tag, or payment ID for incoming transfers. If a memo is required, it will be shared by the project owner—do NOT send funds without the correct memo if one is needed.

5. Confirm transaction details and keep the TXID
   - After sending, save the transaction ID (TXID) and take a screenshot of the transfer confirmation. This makes it possible to verify and trace the payment if needed.

6. Do not share private keys or passwords
   - A legitimate recipient will never ask for your private key, seed phrase, or account password. If asked for those, do not proceed and report the request.

7. Notify the project owner after sending
   - File an issue or contact the owner with the TXID and amount so they can confirm receipt and thank you.
